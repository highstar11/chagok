# 차곡

**차곡차곡 쌓이는 나의 소비와 일상**

차곡은 가계부 앱입니다. 가계부를 쓰다 보면 기록하는 게 번거롭고, 쓰다 보면 어느 순간 열기 싫어지잖아요. 차곡은 그 불편한 부분을 하나씩 다듬어서, 쓰는 동안 기분이 좋고 또 열고 싶어지는 가계부를 만들려고 시작했습니다.

## 만들게 된 이유

가계부 앱은 많은데 쓰다 보면 꼭 한두 군데가 걸립니다. 날짜 하나 바꾸는 데 탭이 너무 많거나, 입력 화면이 답답하거나, 기록이 숫자 목록으로만 쌓이거나요. 기능이 부족해서라기보다 쓰는 느낌이 아쉬운 경우가 많았습니다.

그래서 기능을 많이 넣기보다 **하나하나를 쓰기 편하게** 만드는 데 집중하고 있습니다. 소비를 기록하는 일이 숙제가 아니라 일상의 일부가 되는 게 목표입니다.

## 지향하는 것

- 기록은 빠르고 가볍게
- 화면을 열었을 때 기분이 좋은 디자인
- 한 번 쓰면 계속 쓰고 싶어지는 사용감

## 어떻게 만들고 있나

UX/UI 설계와 디자인, 그리고 개발 일부를 직접 맡고 있습니다. 개발과 운영에는 AI의 도움을 받고 있고, 출시 이후 운영까지 이어서 해볼 계획입니다. 혼자서 어디까지 만들 수 있는지 해보는 프로젝트이기도 합니다.

## 기술 스택

- React Native
- styled-components
- react-native-safe-area-context
- etc.

## 구현된 것들

- **날짜 선택 바텀시트**: 아래에서 올라오는 시트로 날짜를 고릅니다. 배경을 누르거나 핸들을 끌어내리면 닫히고, 오늘 이후 날짜는 선택할 수 없습니다.
- **iOS의 Liquid Glass 적용** : 사용자 경험 측면에서 더욱 만족도를 높이기 위해 Liquid Glass 디자인 시스템을 기반으로 디자인을 설계했습니다.
